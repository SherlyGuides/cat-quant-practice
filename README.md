# CAT Quant Practice

A free, single-page quiz for CAT-style quantitative aptitude: six topic blocks (Numbers, Averages & Mixtures, Arithmetic, Geometry, Algebra, Counting), five questions each.

Every question has four options, a step-by-step solution, and an explanation of the idea behind it, including why the wrong options are tempting. Options are shuffled on every attempt, and your best score per block is kept in your browser.

**Live site:** https://sherlyguides.github.io/cat-quant-practice/

## Content

All questions, solutions and explanations are original, written for practice. They are not taken from any book or past paper.

`questions.json` is generated by `tools/build_questions.py`, which also recomputes every answer and refuses to build if any key is wrong:

```
python3 tools/build_questions.py
```

## Run locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
